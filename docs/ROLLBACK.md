# Rollback

## Registros previos al corte

- DNS anterior.
- IP/CNAME anterior.
- TTL.
- Hosting anterior.
- Versión anterior.
- Backups.

## Procedimiento

1. Revertir registros DNS al origen anterior.
2. Restaurar archivos y base de datos desde backup.
3. Verificar correo, SSL y subdominios.
4. Validar funcionamiento.
