# Design System

## Filosofía

- Contemporáneo, tecnológico, preciso, premium, serio, minimalista.
- Sin plantillas genéricas.
- Sin abuso de glassmorphism ni gradientes gratuitos.
- Movimiento ligero vinculado a la interacción.

## Paleta

| Token | Valor | Uso |
|-------|-------|-----|
| `--color-background` | `#0a0a0b` | Fondo principal |
| `--color-background-secondary` | `#141416` | Fondos elevados |
| `--color-surface` | `#1c1c1f` | Tarjetas y formularios |
| `--color-text-primary` | `#f4f4f5` | Textos principales |
| `--color-text-secondary` | `#a1a1aa` | Textos secundarios |
| `--color-text-tertiary` | `#71717a` | Metadatos |
| `--color-accent` | `#22d3ee` | Acento (uso restrictivo) |
| `--color-border` | `rgba(255,255,255,0.08)` | Bordes sutiles |

## Tipografía

- **Display:** Space Grotesk
- **Body:** Inter
- **Mono:** JetBrains Mono

## Espaciado

- Base 4px/8px.
- Contenedor máximo: `1280px`.
- Padding lateral: `24px` mobile, `32px` desktop.

## Componentes base

- `Container`
- `Heading`
- `Text`
- `Button`
- `Prose`
